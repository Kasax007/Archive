Need more RAM for Minecraft? Here is a handy tutorial.

Details: server pack, updating a server, shaders and memory

How to start the server pack

  • Download the Server Pack of the newest version from the Files tab.
  • Install Java 25 on the server, for example from adoptium.net.
  • Unzip the folder and run start.sh (Linux and macOS) or start.bat (Windows).
  • The first start stops and creates eula.txt. Read the Minecraft EULA and set eula=true in that file.
  • Start again. The Fabric launcher downloads Minecraft 26.3 and starts the server with all mods.

RAM: start.sh gives the server 8 GB. Set another amount with DREAMCRAFT_RAM, for example DREAMCRAFT_RAM=10G ./start.sh. On Windows, change -Xmx8G in start.bat.

Voice chat: Simple Voice Chat needs the UDP port 24454 open on your server.

Updating a server from V1.3: replace mods/raft-*.jar, add mods/upgraded-iron-chests-*.jar and replace the folder config/questsicons/quests. From an older version, also replace mods/QuestIcons-*.jar and add Tamagotchi (mods/tamagotchi-*.jar). Or use the new server pack.

Client-only mods (marked "client" in the mod list) are not in the server pack. Players use the normal Dreamcraft pack.

Play with friends: rent a server at BisectHosting (at least 6 GB) and use my code Kasax007 for 25% off your first month. You can also click Rent a Server in the Dreamcraft main menu. Or run the server pack on your own machine.

Shaders: Iris is included with BSL and Complementary Reimagined. Shaders are off by default. To turn them on, open Options > Video Settings > Shader Packs, pick a pack, make sure the button says "Shaders: Enabled" and click Apply. If your game gets slow, turn them off again in the same screen.

Memory: at least 6 GB. Recommended 8-10 GB normally, or more for those with shaders, a high render distance, increased video settings or HD resource packs.

Java: Dreamcraft 26.3 needs Java 25. The CurseForge app brings the right Java for you.
