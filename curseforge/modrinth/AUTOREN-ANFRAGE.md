# Modrinth-Fassung von Dreamcraft: Erlaubnis der Autoren

Modrinth-Packs laden ihre Mods von Modrinth. Eine Mod, die dort fehlt, darf nur mit Erlaubnis (oder einer freien
Lizenz) in die Pack-Datei. Diese sieben Mods fehlen deshalb in der Modrinth-Fassung (Stand 8.11.2026):

| Mod | Autor | Lizenz / Seite sagt | Kontakt | Fragen? |
| --- | --- | --- | --- | --- |
| Cupboard, Memory Settings, Server Performance – Smooth Chunk Save, Structure Essentials, fix GPU memory leak | someaddon (Someaddons) | All Rights Reserved, nichts zu Modpacks | CurseForge: https://www.curseforge.com/members/someaddon (Kommentare auf den Projektseiten), Patreon: https://www.patreon.com/someaddons. Quellcode-Links stehen in keiner der Mods. | Ja, eine Nachricht für alle fünf |
| More Villagers [Fabric] | SameButDifferent, Zero_DSRS_VX, Drex | Modpacks erlaubt, aber „This curseforge page is the only page that this mod is allowed to be hosted on“ | GitHub: https://github.com/samedifferent/morevillagers/issues, Discord: https://discord.gg/KZwDvzthmK | Ja |
| EpheroLib | iThonk (TheThonk) | LGPL-3.0 | Discord: https://discord.gg/GZjtAn3F6W | Nein: keine Mod im Pack braucht sie |

Quarry Reborn (CC0-1.0 in der Mod-Datei) ist mit Namensnennung im Modrinth-Pack, dafür braucht es keine Anfrage.

## Vorlage (Englisch)

Subject: Permission to include MOD in the Modrinth version of my modpack Dreamcraft

Hi AUTHOR,

I'm Kasax007, the author of the modpack Dreamcraft for Minecraft 26.3 (Fabric):
https://www.curseforge.com/minecraft/modpacks/dreamcraft-new

I'm publishing Dreamcraft on Modrinth as well: https://modrinth.com/modpack/dreamcraft
Modrinth packs download their mods from Modrinth, and a mod that isn't there can only be bundled inside the pack with
its author's permission. MOD isn't on Modrinth, so for now it is left out of the Modrinth version.

May I include MOD (the unchanged Fabric 26.3 file from CurseForge) in the Modrinth version of Dreamcraft? I'll credit
you and link your CurseForge page in the pack's description and changelog. If you'd rather publish it on Modrinth
yourself, I'll simply use it from there.

Thanks a lot for your work!
Kasax007
