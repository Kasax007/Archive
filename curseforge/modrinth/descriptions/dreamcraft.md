<summary><strong>Details: server pack, updating a server, shaders and memory</strong></summary>

<p><strong>How to start the server pack</strong></p>
<ul>
<li>Download the Server Pack of the newest version from the Files tab.</li>
<li>Install Java 25 on the server, for example from <a href="https://adoptium.net">adoptium.net</a>.</li>
<li>Unzip the folder and run start.sh (Linux and macOS) or start.bat (Windows).</li>
<li>The first start stops and creates eula.txt. Read the <a href="https://aka.ms/MinecraftEULA">Minecraft EULA</a> and set eula=true in that file.</li>
<li>Start again. The Fabric launcher downloads Minecraft 26.3 and starts the server with all mods.</li>
</ul>
<p><strong>RAM:</strong> start.sh gives the server 8 GB. Set another amount with DREAMCRAFT_RAM, for example DREAMCRAFT_RAM=10G ./start.sh. On Windows, change -Xmx8G in start.bat.</p>
<p><strong>Voice chat:</strong> Simple Voice Chat needs the UDP port 24454 open on your server.</p>
<p><strong>Updating a server from V1.4:</strong> replace mods/raft-*.jar and mods/QuestIcons-*.jar, replace mods/tamagotchi-*.jar with mods/tamacraft-*.jar (Tamagotchi is now called Tamacraft; worlds carry over) and replace the folder config/questsicons/quests. From V1.3, also add mods/upgraded-iron-chests-*.jar. Or use the new server pack.</p>
<p>Client-only mods (marked "client" in the mod list) are not in the server pack. Players use the normal Dreamcraft pack.</p>
<p><strong>Play with friends:</strong> <a href="https://www.bisecthosting.com/configure?id=597&amp;plan=minecraft&amp;billing_cycle=monthly&amp;game_version=java&amp;modpack=2344&amp;source=mod&amp;aid=4395">order a 6 GB BisectHosting server with Dreamcraft already installed</a> and use my code Kasax007 for 25% off your first month. You can also click Rent a Server in the Dreamcraft main menu. Or run the server pack on your own machine.</p>
<p><strong>Shaders:</strong> Iris is included with BSL and Complementary Reimagined. Shaders are off by default. To turn them on, open Options &gt; Video Settings &gt; Shader Packs, pick a pack, make sure the button says "Shaders: Enabled" and click Apply. If your game gets slow, turn them off again in the same screen.</p>
<p><strong>Memory:</strong> at least 6 GB. Recommended 8-10 GB normally, or more for those with shaders, a high render distance, increased video settings or HD resource packs.</p>
<p><strong>Java:</strong> Dreamcraft 26.3 needs Java 25. The CurseForge app brings the right Java for you.</p>
